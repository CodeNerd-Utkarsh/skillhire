# **App Name**: SkillHire

## Core Features:

- Service Management: Enable freelancers to create, update, and delete service listings, including uploading images. This ensures service details are always current and accurate.
- Service Marketplace: Allow clients to browse services, view detailed service information, and securely purchase services through Stripe or Razorpay.
- Secure User Authentication: Implement user authentication with JWT and bcrypt for secure signup/login functionality, differentiating between freelancer and client roles.

## Style Guidelines:

- Primary color: Teal (#008080) to convey professionalism and trust.
- Secondary color: Light gray (#F0F0F0) for backgrounds to ensure content readability.
- Accent: Gold (#FFD700) for highlights and action buttons to draw attention.
- Clean, grid-based layout for easy navigation and content organization.
- Use simple, consistent icons from a library like FontAwesome for a professional look.
